## How it works

Envite organizes environment variables in four levels:

- **Projects** — an application or service, with its descriptive fields.
- **Environments** — `production`, `staging`… each with its own deploy target.
- **Sections** — groups of variables, written as titled blocks in the `.env` file.
- **Variables** — a key, a value, an optional comment, a secret flag and a state.

The vault is the source of truth. When an environment is ready, envite renders its `.env` file, compares it with the one at the target and writes it there once you confirm.

Start with the [introduction](getting-started/introduction/), or go straight to [installation](getting-started/installation/).
